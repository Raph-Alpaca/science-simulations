실패는 `fail`, 필요한 근거가 없으면 `needs_evidence`, 실행하지 않았으면 `not_run`으로 남긴다. 위 표의 예정 항목을 체크리스트 통과로 옮기지 않는다. 사람 승인도 과학 오류·권한 실패를 통과로 바꾸지 못한다.

증거에는 요구사항 ID, 검토할 버전, 환경/도구 버전, 실행 명령, 실제 결과/종료 코드, 시각, 공개 가능한 근거 위치를 연결한다. 개인 정보·키·원문은 공개 증거에서 제외한다. 문서 점검과 실제 앱 테스트, 모의 시험과 유료/외부 시험을 각각 표시한다.
