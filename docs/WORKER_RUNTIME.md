# 생성 후보의 실제 브라우저 검사

2026-10-04 로컬 구현과 검토한 합성 예제의 실행 결과다. 실제 AI가 생성한 교육 콘텐츠나 원격 Actions 작업을 실행한 결과가 아니다. 운영 제작실·유료 API·공개 콘텐츠는 변경하지 않았다.

## 검사 경로

`runtime-contract.mjs`는 승인 입력 원문의 해시, 후보 파일 바이트·메타데이터·해시, 시도 번호, 기준 코드 SHA를 결합한다. HTML/SVG와 링크, 외부·누락 자산, inline 코드, JavaScript 구문을 소스로 검사하며 후보를 Node 모듈·설치 스크립트·셸·테스트 코드로 실행하지 않는다. 생성기는 `packages/contracts/runtime-spec.js`의 고정된 조작/관찰 표식과 제약을 받는다. 기존 콘텐츠를 이 표식으로 자동 변경하지 않았다.

`runtime-process.mjs`는 별도 Node 프로세스를 시작해 크기가 제한된 JSON만 stdin으로 전달한다. 자식은 OpenAI/Supabase/GitHub/OIDC 토큰·NODE_OPTIONS·프록시 환경을 상속하지 않는다. 결과의 후보/입력/기준 SHA/시도를 다시 대조한다. `runtime-child.mjs`가 새 Chrome에 후보를 메모리에서 제공하고 측정 결과만 반환한다. stdout의 후보 본문이나 임의 메시지를 검사 결과로 해석하지 않는다.

브라우저는 개인 프로필을 사용하지 않으며 chromiumSandbox=true, 새 context, 권한 없음, 다운로드·서비스 워커 차단, offline과 고정 가상 origin의 요청 가로채기를 적용한다. 후보 파일에 있는 GET만 메모리에서 반환하고 나머지 요청·WebSocket·popup·dialog·download를 거부한다. CSP로 inline 실행·frame·worker·form 등도 제한한다. [Playwright launch의 sandbox/env](https://playwright.dev/docs/api/class-browsertype)와 [context의 요청 가로채기/서비스 워커/WebSocket](https://playwright.dev/docs/api/class-browsercontext)를 확인했다.

이 구성은 **브라우저와 프로세스의 제한**이다. 호스트 파일 시스템 전체 격리, OS 수준 네트워크 차단, 메모리/CPU 제한이 검증된 컨테이너/가상 머신을 대신하지 않는다. 실제 생성 코드의 운영 검사는 별도 폐기 가능한 job에서 키·쓰기 토큰·OIDC 없이 수행해야 한다. 이번 PC에서는 검토한 합성 예제만 실행했다. Docker/Podman 명령은 발견하지 못했으며 해당 컨테이너 검증을 했다고 기록하지 않는다.

검사 본체 45초, 브라우저 시작 10초·개별 동작 3초·탐색 5초, 종료 확인 5초다. 부모 프로세스는 55초에 취소를 전달하고 5초 뒤에도 끝나지 않으면 종료한다. 본문 2.3MB·결과 64KiB·요청 200회·기본 페이지 1개·viewport 2개를 제한한다. 취소/시간 초과/종료 미확인은 통과가 아니다. 운영 job의 OS 자원 제한과 전체 종료 확인은 원격 연결 때 추가 검증해야 한다.

## 확인하는 실제 동작

| 영역 | 검사 |
|---|---|
| 공통 | 390px/1440px에서 주 변수 조작, 결과 텍스트와 Canvas/SVG 화면 변화, 초기화 후 변수/결과/화면 복원 |
| 사용성 기초 | 조작부 label, 보이는 가정·한계, 최소 화면 크기, 가로 넘침, reduced-motion 조건 |
| 3D | 실제 WebGL context, 카메라 조작 후 화면 변화, 대체 설명 버튼 |
| WebGL 대체 | context를 얻을 수 없는 상황을 모의로 만들어 대체 설명의 자동 표시 확인 |
| 실패 | 실행 오류·외부 요청·멈춘 스크립트·고장 난 초기화·변하지 않는 그림·후보의 가짜 PASS가 성공으로 기록되지 않음 |

WebGL 관찰은 페이지와 별도 JS world에서 기본 DOM/WebGL 함수를 사용한다. 그림 전후의 screenshot 해시를 남기며 페이지가 출력한 PASS 문자열은 읽지 않는다. 이것으로 3D 과학 모델의 정확성이나 학습 효과가 증명되는 것은 아니다. 접근성 전체, 실제 학생 태블릿, 모든 브라우저·GPU, 오프라인 전체 네트워크 경계도 이번 검사의 범위가 아니다.

## 검토·수정과 보고 연결

파이프라인은 검사를 수행한 후보의 해시·입력 해시·시도 번호를 검토자에게 전달한다. 조작 실패는 개발 역할의 다음 수정 입력으로 전달하며 앞선 실패를 보존한다. 구문/자산 등 소스 계약이 실패해서 브라우저를 실행하지 않은 경우는 `contract=fail, runtime=not_run`을 그대로 유지하면서 수정할 수 있다. 검사 도구 자체가 없거나 실행 근거가 없는 경우는 계속 보류한다. 원래 최대 2회 수정·9회 호출·20분·예산 제한은 유지한다.

보고 API는 `runtime-report.js`의 고정 스키마로 viewport별 관찰, WebGL/카메라/대체 설명, 브라우저 버전·종료·시간·요청 수를 검사한다. 3D 요청은 3D 관찰과 대체 설명 증거가 있어야 통과 보고를 받는다. 입력 해시와 기준 SHA를 인증된 작업/실행과 대조하고 전체 보고 내용의 해시를 계산해 비공개 evidence에 저장한다. 원문 HTML·console·임의 URL·추가 필드는 받지 않는다. 보고 역할의 실제 OIDC와 원격 검사 결과 전달은 아직 연결하지 않았다.

## 실행 결과

`node tests/studio/runtime-browser-check.mjs`: **8/8 기대 결과 일치**, exit0. Chrome **154.0.8037.93**에서 실제 실행했다. 기본 2D·WebGL 3D는 통과했다. 초기화 고장, 정지된 그림, 외부 fetch 시도, 가짜 PASS, 무한 루프 예제는 실패로 판정했고 모두 브라우저 종료를 확인했다. WebGL 불가 사례는 위의 모의 조건이다.

마지막 사례는 실제 별도 프로세스와 브라우저를 파이프라인의 verify에 연결했다. 첫 후보에서 RUNTIME_RESET_FAILED → 모의 개발 응답의 수정본 → 두 번째 실제 검사 통과 → 모의 독립 검토 → 사람 검토 후보 반환을 확인했다. 역할 호출 7회는 전부 모의 응답이며 유료 호출0회다. 첫 실패와 서로 다른 후보 해시를 기록했고 승인·게시를 생성하지 않았다.

최종 비공개 증거는 `.local/evidence/worker/runtime-browser-77bb9dcd-d54d-4150-b96b-1f77aa5a524e.json`, 기록 시각 23:18:13 KST다. 앞선 6사례 결과도 `runtime-browser-4fccff1d-75a7-440c-b544-528274946720.json`에 보존했다. 기준 SHA는 이 합성 검사에서 사용한 자리표시자이며 실제 main/OIDC의 증거가 아니다.

제작실 단위·SQL·HTTP 전체 **97/97**, production build/내장 TypeScript 검사 성공. HTTP 검사에서는 다른 입력 해시와 관찰 없는 통과 보고를 거부하고 보고 내용을 검토 evidence로 돌려주는 것을 확인했다. 해당 HTTP 사례의 관찰은 합성 값이며 실제 브라우저 증거는 위 별도 명령에서 구분한다. 이번 변경에 SQL 수정은 없어 앞선 PostgreSQL11개를 다시 실행하지 않았다.

남은 작업은 폐기 가능한 원격 검사 환경과 워크플로·OIDC/dispatch 연결, 검토 입력 발급, 실제 API 키와 비용 검증, 버전에 결합한 승인·게시·공개 확인이다. 교육과정·교과서 원문 및 AI 처리/공개 권리의 미확인 상태를 유지한다.

후속 [원격 제작 연결](REMOTE_WORKER.md)에서 후보 준비 조회·버전 결합 암호화 전달·검사 결과 대기·제작기 HTTP 어댑터를 추가했고 전체111개가 통과했다. 이는 원격 컨테이너나 실제 Actions의 완료를 뜻하지 않는다. 위8개 브라우저 결과는 앞선 실제 로컬 실행 기록으로 유지한다.
