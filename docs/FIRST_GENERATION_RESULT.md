## 보류 원인과 미완료 사항

교육과정 담당은 주제 및 공개 교재 요약의 개념 범위는 적절하다고 평가했지만, 입력에는 직접 작성한 요약과 링크만 있고 독립 확인 증거는 `unverified`로 전달돼 있어 `needs_evidence`로 판정했다. 코드의 안전한 보류 규칙에 따라 `CURRICULUM_EVIDENCE_REQUIRED`로 종료됐다. 교육과정 원문을 실제 확인한 로컬 기록이 있으나 이를 실행기의 신뢰 가능한 근거로 연결하는 경로가 아직 없다. 기존 기록을 근거 없이 `verified`로 바꾸거나 실패 판정을 지워 통과시키지 않는다.

다음 시스템 작업은 **확인한 공개 원문의 범위·해시·검토 기록을 첫 제작 입력에 연결하는 기능**이다. 일반 개념 중심이라는 사용자 선택과 특정 한국 학교 교과서 일치 여부를 구분해야 한다. 연결 뒤에도 과학·학습 설계·실제 동작 검사는 별개이며 공개 전 최종 버전의 교사 승인을 유지한다. 이번 실제 제작1건 범위는 소진했으므로 새 유료 작업을 자동 시작하지 않는다.

## 종료 처리 주의

DB의 제작 보류/정산 완료를 확인한 뒤 스위치를 닫았는데, GitHub의 마지막 `verify_2 / fetch` 작업은 아직 진행 중이었다. 이후 이 단계가 실패해 **전체 Actions 결과는 failure**다. 차단 시점의 영향이 의심되지만 상세 로그를 확보하지 않아 단정하지 않는다. 생성 담당과 이전 조회는 success이며 DB의 보류 및 비용 기록은 남아 있다. 실패를 숨기거나 재실행하지 않는다. 앞으로는 도메인 작업 종료와 전체 workflow 정리 완료를 모두 확인한 후 정상 차단하고, 비상 차단 시에는 남은 단계 실패를 별도 기록한다.

운영에 적용한 활성화·차단 SQL 및 배포/스위치 결과는 같은 비공개 폴더에 보존한다. 시간과 입력에 묶인 활성화 SQL은 재사용하지 않는다. 첫 작업 전용 트리거는 계속 유지돼 새 제작을 차단한다. 후속 실행에는 별도 검토가 필요하다.
