# 디자인 기본안

## 2026-10-15 디자인 개편 — 차분한 과학 작업실

사용자는 투박한 화면과 AI 템플릿처럼 보이는 색감을 개선하고 세련된 현대적 UI를 요청했다. 기능뿐 아니라 시각적 완성도도 검토한다. 제작실은 교사의 집중 작업 공간, 학생 시뮬레이션은 조작·관찰 중심의 실험 도구로 설계한다.

- 팔레트: Paper `#F5F6F8`, Surface `#FFFFFF`, Ink `#18212F`, Slate `#5B6575`, Line `#DDE2E8`, Cobalt `#2257D5`. 중성색을 바탕으로 주요 행동·선택에만 코발트를 사용한다.
- 글꼴: 설치된 Segoe UI / 맑은 고딕 / Apple SD Gothic Neo, sans-serif. 제목은 굵기·크기·자간으로 위계, 본문은 한국어 가독성 우선. 외부 폰트 요청 없음. 코드 원문에서만 고정폭 글꼴을 쓴다.
- 구성: 낮은 헤더, 간결한 제목, 투명한 대화 사이드바, 넓은 과제 작성 영역, 구분선으로 나눈 진행 영역. 작은 화면에서는 같은 읽기 순서로 쌓인다.

```text
과학 제작실                         공개 자료실 / 계정
탐구를 설계하는 공간                 현재 연결 상태
─────────────────────────────────────────────────────
대화 목록       │ 탐구 요청                 │ 작업 상세
새 대화         │ 주제·대상                 │ 실제 상태
선택한 대화     │ 활동과 관찰할 내용        │ 검토 / 이력
                │ 참고 자료 → 입력 확인     │ 다음 행동
```

동일한 둥근 카드 반복, 파스텔 녹색 바탕, 과도한 그림자·그라데이션·장식용 이모지를 줄인다. 일반 SaaS처럼 보일 위험은 과학 자료를 실제 데이터에 연결한 도식과 조작 중심 배치로 보완한다. 장식적 과학 그림을 얹기보다 정보의 정렬과 탐구 흐름을 시각화한다. 모든 상태는 문구로도 구분하고 초점·확대·동작 줄이기를 유지한다.

첫 유전2D 과제에도 이 방향을 명시한다. 완두·대립유전자·퍼넷 사각형은 SVG/DOM으로 정확히 표현하며 숫자와 문자, 형태를 함께 사용한다. 구현 후 데스크톱/모바일 실제 화면과 접근성을 확인한다. 제작실 UI 변경과 콘텐츠 생성·공개 승인은 각각 기록한다.

별도 Figma/Canva 파일 없이 아래 제안으로 시작합니다.

- 한국어, 큰 글씨, 여백, 명확한 버튼
- 학년·단원·검색, 대상·설명·개념을 담은 카드
- 관리 제작실에는 대화와 실제 작업 상태를 함께 표시
- 상태는 색뿐 아니라 텍스트로 구분
- 시뮬레이션은 예측→조작→관찰→설명, 단계별 공개, 정지/재생/초기화
- 유전자 문자·도형은 실제 데이터와 연결되는 SVG/Canvas/DOM
- 생성 이미지에 유전자형·정확한 개수·중요 문자를 맡기지 않음
- 태블릿 가로/세로, 키보드, 대비, 확대, 동작 줄이기 고려
- 외부 CDN 없이 작동하는 학생용 콘텐츠 우선, 글꼴·이미지 권리 확인
- 디자인 토큰과 공통 컴포넌트로 일관성 유지

참고 사이트는 URL과 좋은 점/원하지 않는 점을 적으면 됩니다. 권리 없는 원본을 그대로 복제하지 않습니다.
