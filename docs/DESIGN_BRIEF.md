# 디자인 기본안

별도 Figma/Canva 파일 없이 아래 제안으로 시작합니다.

- 한국어, 큰 글씨, 여백, 명확한 버튼
- 학년·단원·검색, 대상·설명·개념을 담은 카드
- 관리 제작실에는 대화와 실제 작업 상태를 함께 표시
- 상태는 색뿐 아니라 텍스트로 구분
- 시뮬레이션은 예측→조작→관찰→설명, 단계별 공개, 정지/재생/초기화
- 유전자 문자·도형은 실제 데이터와 연결되는 SVG/Canvas/DOM
- 생성 이미지에 유전자형·정확한 개수·중요 문자를 맡기지 않음
- 태블릿 가로/세로, 키보드, 대비, 확대, 동작 줄이기 고려
- 외부 CDN 없이 작동하는 학생용 콘텐츠 우선, 글꼴·이미지 권리 확인
- 디자인 토큰과 공통 컴포넌트로 일관성 유지

참고 사이트는 URL과 좋은 점/원하지 않는 점을 적으면 됩니다. 권리 없는 원본을 그대로 복제하지 않습니다.
