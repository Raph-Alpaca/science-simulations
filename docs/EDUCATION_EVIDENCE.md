# 교육과정 기준과 원문 검토의 버전 결합

2026-10-05 로컬 시스템 구현. 실제 원문 검토·승인 발급·운영 활성화는 수행하지 않았다.

## 학년도 입력 제거 결정의 반영

사용자가 확인한 v2 요청에는 학년도가 없다. 새 제작 입력도 schoolYear를 받지 않으며 기존 메타데이터와의 호환 값은null이다. 이미 정한 내부2022 개정 기준을 새 입력의 curriculumRevision/curriculumSelection에 넣고, 선택 상태는unverified로 표시한다. 현재 연도나 교육과정 적용 연도를 추정해서 채우지 않는다. 과거에 저장한 입력/해시와 기존 콘텐츠를 다시 쓰지 않는다.

기준 선택은 원문·성취기준·교과서 대조 완료가 아니다. 화면에 ‘2022 개정 · 원문 대조 미확인’을 함께 표시하고 기존 미확인 입력은 그대로 미확인으로 읽는다. 교사가 링크와 직접 작성한 요약을 입력해도 독립 검증 상태로 승격하지 않는다.

## 새 게시 검증 규격

기존 schemaVersion1 게시 승인 검사와 연도 조건은 과거 호환성을 위해 유지한다. 새 revision 범위의 schemaVersion2 승인은 학년도null과 교육과정 revision을 사용하며 **별도 원문 검토 묶음**을 요구한다. 이 경로는 자료실의 실제 승인 발급자와 아직 연결하지 않았다.

원문 검토 묶음에는 콘텐츠ID·정확한 후보 해시·승인 입력 해시·학년·단원·교육과정 revision이 있다. 참고한 모든 sourceId를 중복 없이 포함하며 교육과정/교과서/과학 세 종류의 기록이 모두 필요하다. 기록에는 원문 문서 해시·실제 확인한 쪽/절·검토 범위·검토자 식별자·검토 시각·원문 대조 방법과 판정·AI 이용/요약 공개 허용 여부가 있다. 원문 자체를 담는 필드는 허용하지 않는다. 원문 재배포 허용을 뜻하지도 않는다.

승인보다 늦은 검토, 미확인/실패, AI 의견만 있는 기록, 권리 미확인, 누락/중복/다른 콘텐츠의 근거는 거절한다. 묶음의 정확한 바이트 해시인educationHash를 승인과 현재 신뢰된 검증 스냅샷 양쪽에서 비교한다. 원문이 바뀌고 새 해시로 다시 포장해도 기존 승인과는 일치하지 않는다. 기존 과학/학습/실동작/교육과정/교과서/권리 여섯 검사 및 후보·배포물·정책·lock 해시 조건도 유지한다.

**형식 검증기는 원문 검토를 수행하거나 검토자의 권한을 증명하지 않는다.** 실제 발급 서비스는 비공개 신뢰 저장소의 검토 기록·원문 해시와 교사 권한을 확인해야 한다. 생성 코드/모델/브라우저가 만든 JSON을 그 저장소 대신 받아서는 안 된다. 현재 productionInputs는 계속 신뢰된 승인 발급자 부재로 공개 콘텐츠를 선택하지 않고, 제작 결과 UI의 게시 적격도false다. 완료되지 않은 원문 검토를 대체하는 우회 경로가 아니다.

## 검증 범위

합성 문서/검토자만 사용한 새4개 단위 검사로 v1 호환, 연도 없이 v2의 엄격한 근거 요구, 모든 차원 불일치, 권리/근거 누락·임의 추가·원문 바이트 변조·다른 최신 검증 해시 거절을 확인했다. 관련 입력/결과 검사와 함께15개 통과. 실제 교육 자료를 검토했다고 기록하지 않았다. 전체 회귀와 빌드 결과는 STATUS의 최신 항목에 남긴다.

검사 컨테이너에 새 계약 모듈을 포함하고, 복사한 실행 진입점의 실제 import 그래프를 번들링하여 전이 의존성 누락을 검사한다. 실제 Docker 실행은 별도 미검증이다.
