# 2026-10-05 멘델 시제품의 교육과정 부분 대조

공식 원문을 실제 확인하고 시제품의 조사·소통 활동을 보완했다. **확인한 단원의 부분 대조이며, 전체 교육과정·선정 교과서 적합성이나 게시 승인 완료가 아니다.** 이번 검토는 주 에이전트가 수행했다. 새 독립 검토자는 실행하지 않았다.

## 확인한 자료와 범위

[교육부 2022-33호 고시 게시물](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0)의 첨부2에서 별책9 과학과 HWP를 내려받아 읽었다. 제공된 로컬 PDF의65쪽(인쇄59쪽), `(21) 생식과 유전`의 9과21-01~05·탐구 활동·해설·적용 고려 사항을 대조했다. PDF65·66쪽을 렌더링해 직접 확인했고66쪽은 다음 단원이다.

공식 HWP의 해당17개 문단과 PDF 단원의 전체 텍스트 순서는 공백·문장부호를 제외한 비교에서 일치했다. HWP/PDF의 바이너리 동일성이나 전체292쪽 대조 결과가 아니다. 이후의 모든 수정 고시를 조사하여 최신 통합본이라고 판정한 것도 아니다. 원문 해시·범위·미확인 항목은 [기계 판독 기록](../references/reviews/curriculum-2022-mendel.json)에 남겼다.

9과21-04는 멘델 원리 설명뿐 아니라 관련 현상 조사와 협력적 의사소통을 포함하며, 단원은 유전 모의 활동을 제시한다. 이를 바탕으로 기존 조작 활동에 공개 완두 자료 조사, 모둠별 표본 비교, 근거에 따른 설명 수정 안내를 추가했다. 이 안내의 학습 효과를 실제 학생에게 시험하지는 않았다.

원문 검색에서 우열·분리·독립의 개별 명칭이 나오지 않는다는 사실만으로 해당 원리가 교육과정에서 제외됐다고 판정하지 않는다. 원문은 멘델 원리를 포괄적으로 다룬다. 독립의 법칙의 수업 깊이와 필수/보충/심화 위치는 선정 교과서·수업 계획을 추가 확인해야 한다. 콘텐츠의 중3 표시는 기존 사용자 주제 설정이며 이번 부분 대조가 학년 배치를 확정하지 않는다. 학년도 입력을 제거한 사용자 결정은 유지한다.

과학 설명은 [OpenStax12.1의 멘델 실험](https://openstax.org/books/biology-2e/pages/12-1-mendels-experiments-and-the-laws-of-probability)과 [12.3의 유전 원리](https://openstax.org/books/biology-2e/pages/12-3-laws-of-inheritance)에서 실제 읽은 교배·분리·독립·연관 제한의 범위로 확인했다. 한국의 선정 교과서 검토를 대신하지 않는다. 원문·그림을 콘텐츠에 복제하지 않았으며 외부 AI 처리와 재배포 권리도 확인 완료로 바꾸지 않았다.
