## 02단계에 전달할 최소 계약

현재 앱 코드와 패키지 파일은 없다. 다음 명령은 02단계에서 실제 스크립트를 정의한 뒤에만 루트 `C:\Users\user\Desktop\science-simulations`의 Windows PowerShell에서 사용한다.

| 미래 명령 | 목적 |
|---|---|
| `npm.cmd run dev:catalog` | 로컬 자료실 |
| `npm.cmd run validate` | 콘텐츠 계약·경로·중복·공개 적격 검사 |
| `npm.cmd run test` | 계산·계약·회귀 단위 검사 |
| `npm.cmd run test:e2e` | 실제 브라우저 기능·접근성 검사 |
| `npm.cmd run build:catalog` | 승인된 파일만 dist/catalog로 출력 |

`npm.cmd ci`는 잠금 파일 생성 후 재현 설치에 사용한다. 지금 실행하지 않는다. PowerShell 실행 정책 변경, WSL 전환, Git 초기화, 원격 연결을 02의 암묵적 선행 작업으로 넣지 않는다. 로컬 시제품은 Git 없이 만들 수 있으며 신뢰된 main/커밋 기반 자동화는 04 이후에만 가능하다.

## 설계와 검증의 인수 조건

- 개발자는 [DATA_CONTRACTS](DATA_CONTRACTS.md)를 실제 스키마/타입/검사로 옮기고, 바뀐 계약은 version과 이관 계획을 기록한다.
- 검사 구현은 콘텐츠 구현과 분리한다. 콘텐츠 PR이 테스트 기준을 삭제하거나 수정하여 통과하는 방식은 허용하지 않는다.
- 검토자는 [VERIFICATION_MATRIX](VERIFICATION_MATRIX.md)의 해당 단계 항목별로 명령·실행 환경·후보/아티팩트 해시·결과를 남긴다. 미실행은 미검증이다.
- 실제 UI·과학 모델·교육과정 적합성은 각각 증명한다. 브라우저 자동 검사만으로 학습 효과나 실제 태블릿 사용성을 완료 처리하지 않는다.
- 현재 설계의 입력 공백은 [OWNER_INPUT](OWNER_INPUT.md)의 시점별 표로 관리한다. 새 의존성·서비스 변경·권한 변경이 필요하면 해당 시스템 변경으로 분리한다.
