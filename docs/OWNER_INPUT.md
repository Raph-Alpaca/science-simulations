# 선생님 입력 — 먼저 확인하세요

대괄호 항목은 미확정입니다. 비밀 키·로그인 정보를 쓰지 마세요.

## 이미 반영한 방향
- 사이트 이름(가안): 과학 시뮬레이션 자료실
- 관리 앱(가안): 과학 시뮬레이션 제작실
- 저장소: Raph-Alpaca/science-simulations (Public, 기존 저장소 사용)
- 대상: 중학교 과학, 학년·단원별 카드
- 첫 주제: 중3 생식과 유전 — 우열의 원리, 분리의 법칙, 독립의 법칙
- 목적: 학생 이해를 돕는 교사 시연과 학생 조작
- 핵심 학습: 부모 대립유전자 → 생식세포 → 수정 → 자손
- 최종 입력: 문자 채팅 + 받아쓰기 + 실시간 음성 대화
- 초기 공개: 사람 승인, 이후 검증된 신규 콘텐츠만 자동화
- 학생 로그인/개인정보 수집/학생용 AI 호출: 사용하지 않음

## 선생님이 확정할 사항
- 적용 학년도: [실제 수업 연도 입력]
- 적용 교육과정: [실제 원문 확인 후 학년별로 구분]
- 교과서 출판사/저자/판본/쪽수: [미확인]
- 교과서 대조 수준: [엄격한 일치 / 일반 개념 중심]
- 실제 기기·브라우저: [예: 교사 PC 크롬, 학생 태블릿]
- 추가로 피할 오개념: [선택]
- 하루 최대 제작 작업 수: [첫 유료 실행 전 결정]
- 월 비용 허용 범위: [공급사 대시보드 확인 후 결정]
- 자료별 외부 AI 제공·공개 사용 허용: [확인 필요]

학년도·교과서가 비어 있으면 시제품은 가능하나 정합성 검토 완료로 처리하지 않습니다. 교사 UUID·이메일·키는 공개 문서 대신 서버 설정에 둡니다.
