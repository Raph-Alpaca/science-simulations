# 원문 검토 기록과 게시 준비 발급

2026-10-14 로컬 구현·검사 기록이다. PR #10의 승인 화면/서버는 배포됐지만 승인·준비 SQL은 아직 운영에 적용하지 않았다. 이 작업은 실제 원문 검토, 교사 승인 또는 학생용 게시를 발급하지 않는다.

## 준비 기록을 만드는 경로

`source_reviews`는 검토자가 실제 확인한 원문 근거를 저장하는 별도 권위 기록이다. 소유 교사·작업·입력·후보 버전과 근거 묶음의 해시를 결합한다. 앱 서버의 service_role과 브라우저 역할은 이 기록을 만들거나 고칠 수 없다. 처음 철회하는 것 외에는 기존 기록을 수정·삭제할 수 없다.

`automation/publish/prepare-review.mjs`는 완료된 제작 결과, 저장된 원문 검토 기록, 신뢰된 기존 자료실을 받는다. 후보 파일을 재작성하지 않고 전체 자료실 묶음과 게시 제안을 만든 뒤 기존 승인 서비스와 같은 검증을 수행한다. 실제 원문을 읽거나 근거의 진실성을 새로 인증하는 함수는 아니다. 미확인 교과서나 모델의 검토 주장으로 원문 검토 기록을 채우면 안 된다.

`automation/publish/review-issuer.mjs`는 별도로 주입한 권위 있는 DB 연결을 통해 저장 기록을 읽고 준비 발급을 요청한다. 키나 환경파일을 읽지 않으며 모델 실행기·브라우저 경로에 연결하지 않는다. 호출당10초 제한, 자동 재시도 없음이다. 운영 발급자 계정과 연결은 아직 준비하지 않았다.

`supabase/proposals/studio_release_preparation_v1.sql`은 승인 SQL 다음에 검토할 제안이다. 발급 시 DB가 작업 잠금 아래 최신 상태·근거·피드백·자료실 기준을 다시 확인한다. 교육 근거는 요청 본문 대신 원문 검토 테이블에서 복사한다. 동일 요청은 같은 준비 기록을 반환하고, 내용이 다른 재전송은 거부한다. 작업당 준비 기록은 최대20개이며 기존 기록은 지우지 않는다. 앱 service_role에는 읽기 전용 원문 조회만 허용하고 준비 읽기/발급 RPC의 실행 권한은 주지 않는다.

## 변경과 철회

원문 근거를 철회하거나 기준 자료실을 바꾸면 그 기록을 사용한 준비·승인의 현재 효력이 사라진다. 해결되지 않은 수정 요청이 있으면 최신 피드백 해시만 붙여 새 준비를 발급해도 거부한다. 이전 SQL에서 만들었던 원문 기록 연결이 없는 준비는 이력을 보존하되 이후 게시 권한으로 쓰지 않는다. 승인 시각이나 교사 행위는 준비 발급자가 만들 수 없다.

발급, 원문 철회, 교사 피드백과 승인, 기준 변경이 공통 잠금 순서를 따른다. 게시의 외부 전송은 아직 이 트랜잭션에 포함되지 않으며, 이 단계의 성공을 실제 게시 완료로 표시하지 않는다.

## 검증 결과

- 로컬 DB/서비스8/8 PASS: 정확한 후보 바이트, 중복 요청, 권한 분리, 원문/권리/소유자 불일치, 철회와 불변성, 미해결 수정 요청, 오래된 근거,20개 상한, 별도 발급자 어댑터를 검사했다. 마지막 실행은 exit0이다.
- 실제 PostgreSQL17의 독립 연결 경합7/7 PASS: 중복 발급, 발급/피드백 양방향, 원문 철회/발급 양방향, 기준 변경/발급, 원문 철회/교사 승인을 검사했다. 각 경우 실제 잠금 대기를 관찰했고 검사 DB 종료도 확인했다.
- 권위 있는 발급·원문 변경 역할은 합성 관리자 연결이며 교사 명령은 비관리 service_role 연결이다. 모든 검사 연결은 일반 트리거 모드였다. 합성 스냅샷 복원 때만 복원 모드를 사용했다.
- 최초 두 경합 검사는 결과를 JSON으로 읽는 검사 쿼리의 변환 누락으로 첫 경우 이후 실패했다. 쿼리에 `to_jsonb`를 추가했고 운영 SQL이나 안전 조건을 완화하지 않았다. 실패 기록을 보존했다.

성공 증거는 `.local/release-postgres17-21c99aaa-f46f-48d2-b5dd-0d8b9315782f/result.json`에 있다. 이전 실패는 같은 접두사의 `d151fe2e-b6b1-4a58-a16a-0626b3f61e40`, `b1e3e869-75b3-4b4a-a17a-31a273898770` 폴더에 보존한다. 이 검사들의 교육 자료·모델 응답·원문 확인·교사 행위는 합성이며 유료 호출과 운영 게시가 없다.

## 남은 연결

실제 원문 확인과 발급자 자격, 운영 SQL 적용, 신뢰된 전체 자료실 기준 등록, 게시 접수·철회 경쟁 제어, 동일 파일 배포, 공개 URL의 파일/동작 확인과 release 기록이 남아 있다. 개인 에이전트도 같은 기록과 교사 승인 규칙을 사용해야 한다.
