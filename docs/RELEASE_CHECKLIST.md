# 공개 전 체크리스트

- [ ] 학년도·교육과정·교과서 대조 상태가 명확하다.
- [ ] 모형 가정·오개념·확률 계산을 확인했다.
- [ ] 실제 기능·회귀·접근성 검사를 수행했다.
- [ ] 승인한 버전과 배포할 콘텐츠 해시가 같다.
- [ ] 초안·비공개 원문·키가 Git/로그/배포물에 없다.
- [ ] 미로그인·타인·위조 job 요청이 차단된다.
- [ ] 생성 코드가 검사·공개 기준을 바꾸지 못한다.
- [ ] 중복·취소·API 실패·시간 초과를 시험했다.
- [ ] 입력 방식에 무관하게 같은 권한·검사를 적용한다.
- [ ] 재접속 후 실제 작업 상태가 복원된다.
- [ ] 공개 주소·직접 링크·새로고침을 확인했다.
- [ ] 이전 정상 버전 복구를 실제로 시험했다.
- [ ] 실제 수업 기기·설명 흐름을 직접 확인했다.
- [ ] 미검증 항목을 완료라고 표시하지 않았다.

체크는 실제 증거를 남긴 뒤 합니다.
