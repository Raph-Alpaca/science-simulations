# 승인한 자료실 파일의 격리 실행 검사

2026-10-14 로컬 검증 단계다. 준비한 동일 바이트를 하위 경로 `/science-simulations/`에서 검사한다. 실제 배포·게시 권한 소비·게시 완료 기록은 아직 없으며 운영 기능도 비활성이다.

서버가 이미 확인한 제안 원문(식별자·해시·진입점)과2D/3D 유형만 검사 설명으로 전달한다. 비공개 교육 원문은 포함하지 않는다. 제안 해시·자료실 해시·대상 콘텐츠 파일 해시·meta.json의 ID/진입점을 다시 대조하고, 설명을 암호화 봉투v2의 인증 데이터로 결합한다. 원래 후보 파일이나 자료실 파일을 수정·재빌드하지 않는다. v1 봉투는 새 검사에서 거절하며, 기존 v1을 운영에서 생성한 적은 없다.

실제 자료실 UI를 열고 전체 카드의 목적지가 저장 파일에 있는지, 표시된 링크로 승인한 시뮬레이션에 도달하는지 확인한다.390/1440px 조작·출력/화면 변화·초기화·넘침을 검사하며3D는 카메라·WebGL·대체 설명도 확인한다. 네트워크는 저장된 같은 출처 파일만 route로 제공하고, 외부 통신·팝업·다운로드·추가 탐색·웹소켓을 차단한다. 브라우저의 과학적 타당성 평가는 별도 검토 근거를 대신하지 않는다.

기존 컨테이너에 검토한 게시 모드 진입점과 순수 검사 모듈만 추가했다. cap-drop ALL·seccomp·no-new-privileges·읽기 전용·network none·호스트 마운트 없음·pwuser·Chromium sandbox·2GiB/CPU2/pids128/65초와 삭제 확인은 그대로다. 후보는 stdin의 불활성 JSON이며 Node 모듈·명령·설정으로 실행하지 않는다. 이미지 빌드 허용 목록과 COPY 대상에 순수 파일만 포함한다.

verify job에는 OIDC/Pages 권한·OpenAI/DB 키가 없다. 전달 키는 신뢰된 호스트 래퍼만 사용하고 컨테이너에 보내지 않는다. 입력 봉투의 승인/실행/SHA/파일 해시를 확인한 뒤 exclusive claim을 먼저 저장해 같은 작업의 재시작을 거절한다. 검사 결과는 별도 키 파생 영역의 AES-GCM 암호문으로 저장하며 공개 Actions에는 암호문만1일 보존한다. 보고서에는 고정 검사 코드·숫자·해시만 허용하고 원문/브라우저 오류 원문을 넣지 않는다. 검사 실패도 실패로 보관하며 CLI는exit1이다. 이 성공 결과는 아직 DB의 게시 허가가 아니다.
