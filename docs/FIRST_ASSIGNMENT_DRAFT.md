# 첫 실제 제작 과제 초안 — 완두의 유전

2026-10-15. 선생님이 **기존 유전 주제·2D, 일반 개념 중심**으로 진행하도록 확인했다. 아래 세부 요구사항은 검토 가능한 초안이며 주제 선택만으로 자료 권한·유료 실행·게시가 승인된 것은 아니다. 기존 `mendel-inheritance` 시제품과 주소는 유지하며, 새 제작 요청의 콘텐츠 ID는 제작실에서 별도로 발급한다.

## 입력할 과제

- 제목: 완두의 대립유전자는 어떻게 자손에게 전달될까요?
- 학년·단원: 중3, 생식과 유전. 학년도는 입력하지 않는다.
- 유형: 2D. 첫 시험은 우열과 분리에 집중한다. 독립의 법칙과 3D는 이후 별도 요청에서 다룰 수 있다.
- 검토 수준: 일반 개념 중심. 공개 교재는 OpenStax Biology 2e를 사용하며 한국의 특정 학교 교과서 일치 여부는 미확인으로 표시한다.
- 학생 활동: 예측 → 부모의 유전자형 선택 → 생식세포·수정 관찰 → 이론과 모의 표본 비교 → 근거를 들어 설명 수정.

요구사항 초안:

> 일반 개념 중심의 중3 유전 2D 시뮬레이션입니다. 한국의 특정 학교 교과서 일치는 미확인으로 표시하고, 공개 교재 OpenStax Biology 2e 12.3의 설명을 참고하세요. 완두의 씨 모양 한 형질을 완전 우성 모형으로 다룹니다. 부모 각각의 RR/Rr/rr를 선택하면 대립유전자 하나씩이 생식세포로 전달되고 수정 때 다시 짝을 이루는 과정을 단계별로 보여 주세요. 예측을 먼저 남긴 뒤 퍼넷 사각형과 자손의 유전자형·표현형 확률을 확인하게 해 주세요. RR×rr와 Rr×Rr를 비교하고, 이론적 확률과 무작위 모의 표본의 관찰값은 별도로 표시해 주세요. 표본 수는 10·100·1000 중 선택하고, 초기화와 키보드 조작을 지원하며 색 외에 문자·모양으로 구분해 주세요. 우성은 우수함이나 집단 내 흔함을 뜻하지 않고, 열성 대립유전자가 사라지는 것도 아님을 설명해 주세요. 공개 자료에서 멘델 실험의 의미를 조사하고 모둠별 표본 결과를 비교해 설명을 고치는 활동을 넣어 주세요. 단일 유전자·완전 우성·같은 생존 가능성을 가정하는 교육용 모형이며 실제 재배 실험이나 모든 유전 현상을 재현하지 않는다고 표시해 주세요. 독립의 법칙·사람의 질병·학생 가족 정보는 이번 범위에서 다루지 않습니다. 교육과정과 선정 교과서에서 확인하지 않은 내용은 검토 완료라고 표시하지 마세요. 화면은 현대적인 과학 실험 도구처럼 구성해 주세요. 흰색과 차가운 밝은 회색 바탕, 짙은 먹색 글자에 코발트 블루를 절제해 사용하고, 과한 파스텔색·그라데이션·둥근 카드 반복·장식용 이모지는 피하세요. 한국어 시스템 글꼴의 명확한 크기 위계와 충분한 여백, 얇은 구분선으로 조작부·관찰 장면·확률 결과를 구별해 주세요. 부모 선택과 단계 조작은 관찰 장면 옆에 모으고, 대립유전자·퍼넷 사각형·표본 결과를 실제 데이터에 연결한 정교한 SVG/DOM으로 표현해 주세요. 작은 화면에서는 관찰과 조작이 자연스럽게 이어지고, 색 없이도 문자·모양으로 읽히며, 키보드 초점과 동작 줄이기 설정을 지원해야 합니다. 외부 글꼴/CDN 없이 동작하게 해 주세요.

## 확인한 공개 근거

1. [교육부 고시2022-33호, 첨부2의 별책9](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0): 인쇄59쪽/PDF65쪽, `(21) 생식과 유전`, 9과21-04 및 탐구 활동. 멘델 원리 이해와 관련 현상 조사·협력적 소통, 유전 모의 활동에 연결한다. 10월5일의 부분 대조 기록을 재사용했으며 이번에 받은 공식 HWP의 SHA256도 일치했다. 원문을 프롬프트에 복사하지 않고 링크·범위·자체 요약만 준비한다. 모든 수정 고시와 실제 수업 학년 배치의 검증을 뜻하지 않는다.
2. [OpenStax Biology 2e,12.3](https://openstax.org/books/biology-2e/pages/12-3-laws-of-inheritance): `Alleles Can Be Dominant or Recessive`, `Equal Segregation of Alleles`. 완전 우성 모형에서 이형접합체의 두 대립유전자가 생식세포로 나뉘며, Rr×Rr의 이론적 유전자형 비율1:2:1과 표현형 비율3:1을 설명하는 근거로 사용한다. 이 외의 유전 양상도 있으므로 보편 법칙으로 과장하지 않는다. 한국의 선정 교과서 대조를 대신하지 않는다.

3. [미국 NHGRI, Mendelian Inheritance](https://www.genome.gov/genetics-glossary/Mendelian-Inheritance): Definition 절을 실제 읽었다. 멘델이 완두의 형질 전달 실험에서 우성·열성 유전 양상을 설명했다는 역사·과학 맥락의 근거다. 이 짧은 정의를 확률 계산이나 교육과정 대조의 근거로 확대하지 않는다.

교육과정 근거의 실제 확인 범위·해시는 [기존 부분 대조 기록](CURRICULUM_MENDEL_REVIEW.md)에 있다. 이번 재확인 증거는 Git 제외 폴더 `.local/reference/first-generation-20261014/source-check.json`이다. 과학적 계산, 학습 설계, 실제 조작은 새로 생성될 후보마다 별도로 검사한다.

## 남은 확인과 실행 조건

- 주제·2D·일반 개념 중심은 사용자 확인 완료다. 선생님은 위 세부 요구사항을 수정할 수 있다.
- OpenStax는 공개 교재 근거로 사용한다. 한국 학교의 선정 교과서와 일치했다고 기록하지 않는다. 교육과정의 실제 대조 범위는 위 단원에 한정하며, 실행기는 필수 근거가 부족하다고 판정하면 보류할 수 있다.
- 2026-10-15 사용자에게 공개 요약3개 OpenAI 전달·첫 제작1건 1,000원 범위의 명시 승인을 받았다. 최신 디자인 요구를 포함한 입력 버전의 동의를 제작실에 저장했고 첫 실행1건을 접수했다. 최종 게시 승인은 포함하지 않는다.
- 실제 worker·dispatch·DB 예산 활성화는 아직 수행하지 않았다. 월10,000원/10건, 작업당1,000원·동시1건·최대2회 보완을 유지한다. 실패·근거 보류에도 이미 발생한 API 비용은 남는다.
- 생성물 검토·수정 뒤 선생님이 그 최종 버전을 승인한 경우에만 학생용 게시를 진행한다.
