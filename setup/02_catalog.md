# 02 공개 자료실 기반 제작

현재 프로젝트를 유지하고 README.md, AGENTS.md, docs/OWNER_INPUT.md, docs/SYSTEM_SPEC.md, docs/STATUS.md 및 실제 Git 상태를 먼저 확인하세요. 현재 단계만 진행하고 최신 공식 문서로 API·설정을 확인하세요. 실제 키를 읽어 출력하지 마세요. 완료 시 변경 파일, 실제 실행 명령과 결과, 미검증 사항, 다음 사용자 작업을 남기고 docs/STATUS.md를 갱신하세요. 다른 단계까지 무작정 진행하거나 구현되지 않은 기능을 완료로 보고하지 마세요.

apps/catalog에 한국어 과학 시뮬레이션 자료실을 실제 구현하세요. 전체/중1/중2/중3, 단원 필터, 검색, 키보드 조작, 태블릿 대응을 제공하세요. 카드에는 제목·학년·단원·개념·짧은 설명·실행 링크를 표시하세요.

content/simulations/<stable-id>/meta.json을 스키마 검증한 뒤 카드 목록을 생성하세요. 학년·단원 표기는 공통 설정으로 통일하고 제목 변경과 고유 ID 변경을 분리하세요. 중복 ID, 경로 이탈, 누락 필드, 깨진 링크는 실패시킵니다. 메타데이터의 임의 HTML은 실행하지 않고 텍스트로 표시하세요.

공개 가능한 콘텐츠는 신뢰된 승인 기록과 콘텐츠 해시/커밋으로 결정하세요. meta.json의 status 자기 선언만으로 통과하지 마세요. 초안·보류 콘텐츠의 실행 파일과 비공개 자료는 dist/catalog에서 제외합니다.

원본/계산/화면을 검사하기 쉽게 분리하고, npm run dev:catalog, validate, test, test:e2e, build:catalog를 실제로 정의하세요. 루트 실행 경로는 README에 정확히 쓰세요. 고정된 의존성·잠금 파일을 사용하세요.

GitHub Pages의 /science-simulations/ 하위 경로를 모사해서 직접 링크·새로고침·필터·빈 상태를 실제 브라우저로 검사하세요. Playwright와 접근성 검사를 구성하세요. 아직 공개 교육 콘텐츠가 없으면 정직한 빈 화면을 보이고 가짜 완성 카드를 만들지 마세요.

이번 단계에서 관리 앱·API·DB·외부 배포를 시작하지 않습니다.
