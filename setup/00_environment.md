# 00 환경 확인

이 프로젝트에서 ‘문장·음성으로 운영하는 중학교 과학 시뮬레이션 제작실’을 만들겠습니다. 지금은 환경 확인만 하세요.

실제 읽기 전용 명령으로 운영체제, 현재 셸, 작업 폴더, 기존 파일, Git 저장소/브랜치/미커밋 변경, Git·Node.js·npm 설치 버전을 확인하세요. 현재 Codex가 사용할 수 있는 파일 읽기·명령 실행·검색·브라우저·실제 하위 에이전트 도구도 확인하세요. 모르는 것은 미검증이라고 표시하세요.

아직 설치·파일 수정·유료 호출·외부 배포·기존 파일 삭제를 하지 마세요. 비밀 키·토큰·.env 내용은 읽어 출력하지 마세요. 필요한 설치만 운영체제에 맞는 공식 경로로 안내하고, 현재 지원되는 Node.js LTS와 라이브러리 지원 범위를 확인하세요. Windows 네이티브와 WSL을 무심코 혼용하지 마세요.

먼저 docs/OWNER_INPUT.md, docs/SYSTEM_SPEC.md가 있는지만 확인한 뒤 비밀 없는 문서를 읽으세요. 결과는 확인됨/설정 필요/미검증으로 나누고, 제가 다음에 할 일을 세 가지 이하로 알려 주세요. 질문에 대한 답이 문서에 있으면 다시 묻지 마세요.
