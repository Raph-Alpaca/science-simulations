# 12 새 대화에서 이어하기

현재 프로젝트를 유지하고 README.md, AGENTS.md, docs/OWNER_INPUT.md, docs/SYSTEM_SPEC.md, docs/STATUS.md 및 실제 Git 상태를 먼저 확인하세요. 현재 단계만 진행하고 최신 공식 문서로 API·설정을 확인하세요. 실제 키를 읽어 출력하지 마세요. 완료 시 변경 파일, 실제 실행 명령과 결과, 미검증 사항, 다음 사용자 작업을 남기고 docs/STATUS.md를 갱신하세요. 다른 단계까지 무작정 진행하거나 구현되지 않은 기능을 완료로 보고하지 마세요.

이 프로젝트를 새로 시작하거나 다시 만들지 마세요. README.md, AGENTS.md, docs/SYSTEM_SPEC.md, docs/DECISIONS.md, docs/STATUS.md와 현재 Git 상태를 먼저 읽으세요. 키/.env 내용은 읽어 출력하지 않습니다.

현재 브랜치, 미커밋 변경, 마지막 정상 커밋, 구현된 단계, 실제 검증 여부, 누락 설정을 대조하세요. 문서의 완료 표시와 실제 코드가 다르면 불일치를 알리세요. 외부 계정에 접근하지 않았다면 접속 확인 완료라고 하지 마세요.

현재 단계의 가장 작은 다음 작업을 제안한 뒤, 이미 허용된 범위에서 진행하세요. 기존 파일 삭제·reset --hard·강제 push·보호 규칙 해제·전체 키 교체로 문제를 덮지 마세요.

오류가 있으면 실제 재현→원인 분리→최소 수정→같은 검사 재실행 순서로 처리하세요. 유료 호출·공개 배포·데이터 삭제 등 영향 큰 작업은 다시 대상과 영향을 확인합니다. 완료 후 STATUS를 갱신하세요.
