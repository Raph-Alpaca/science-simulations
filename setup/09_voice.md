# 09 음성 받아쓰기

현재 프로젝트를 유지하고 README.md, AGENTS.md, docs/OWNER_INPUT.md, docs/SYSTEM_SPEC.md, docs/STATUS.md 및 실제 Git 상태를 먼저 확인하세요. 현재 단계만 진행하고 최신 공식 문서로 API·설정을 확인하세요. 실제 키를 읽어 출력하지 마세요. 완료 시 변경 파일, 실제 실행 명령과 결과, 미검증 사항, 다음 사용자 작업을 남기고 docs/STATUS.md를 갱신하세요. 다른 단계까지 무작정 진행하거나 구현되지 않은 기능을 완료로 보고하지 마세요.

관리 채팅에 마이크 받아쓰기 기능을 추가하세요. 기존 작업 등록·인증·승인 경로를 재사용합니다. 별도의 음성 우회 권한을 만들지 마세요.

녹음 시작/중지/취소, 상태 표시, 인식된 텍스트 편집과 전송을 제공합니다. 전사 API는 서버에서 호출하고 길이·크기·형식·호출 빈도를 제한하세요. 원본 녹음은 기본 저장하지 않고 처리 후 정리합니다. 학생 음성/개인정보 수집 용도로 확장하지 마세요.

OpenAI의 현재 지원 모델/형식을 공식 문서로 확인하고 환경 설정으로 관리하세요. 브라우저 기본 음성인식만으로 모든 기기를 보장하지 마세요. HTTPS와 마이크 권한 거절 때 문자 대체 경로를 제공하세요.

‘중3, 우열의 원리, 분리의 법칙, 독립의 법칙’ 인식 확인, 빈 오디오, 잡음, 중복 클릭, 전사 실패, 취소, 실제 PC와 사용 기기 테스트를 수행하세요. 아직 실제 기기가 없으면 그 항목은 미검증입니다.

받아쓰기는 실시간 음성 대화와 다릅니다. 완료 보고에서 구분하고 다음 13_realtime 확장을 위한 입력 계층을 분리하세요.
