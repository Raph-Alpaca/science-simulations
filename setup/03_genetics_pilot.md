# 03 유전 시범 콘텐츠

현재 프로젝트를 유지하고 README.md, AGENTS.md, docs/OWNER_INPUT.md, docs/SYSTEM_SPEC.md, docs/STATUS.md 및 실제 Git 상태를 먼저 확인하세요. 현재 단계만 진행하고 최신 공식 문서로 API·설정을 확인하세요. 실제 키를 읽어 출력하지 마세요. 완료 시 변경 파일, 실제 실행 명령과 결과, 미검증 사항, 다음 사용자 작업을 남기고 docs/STATUS.md를 갱신하세요. 다른 단계까지 무작정 진행하거나 구현되지 않은 기능을 완료로 보고하지 마세요.

첫 시범 콘텐츠 ID는 mendel-inheritance입니다. 기존 자료실에 ‘중3·생식과 유전’ 카드로 연결하되 검토가 끝나기 전에는 공개하지 마세요. 학년도·교육과정은 OWNER_INPUT과 실제 자료로 확인합니다.

교육과정 검토자와 교과 자료 검토자가 독립적으로 근거를 확인하고, 학습 설계자·개발자·독립 검토자가 작업하게 하세요. 실제 하위 에이전트가 없으면 별도의 실행 문맥으로 순차 작업하며 방식을 밝히세요. 토론문을 실행 결과라고 하지 마세요.

핵심 목표는 부모의 대립유전자→생식세포→수정→자손의 연결입니다. 예측·조작·관찰·설명 순서, 단계별 공개, 일시정지/재생/초기화, 큰 글씨, 색상 외 문자·모양 구분을 구현하세요.

우열: 완전 우성의 씨 모양 RR×rr에서 자손 Rr을 보여 주세요. r은 사라지지 않습니다. 우성은 우수함·힘·집단 내 빈도가 아닙니다.
분리: 부모를 RR/Rr/rr로 선택합니다. 생식세포에는 해당 유전자의 대립유전자 하나만 들어갑니다. Rr×Rr은 이론적으로 RR:Rr:rr=1:2:1, 표현형=3:1입니다.
독립: R/r 씨 모양, Y/y 씨 색깔, RrYy×RrYy를 사용합니다. 두 유전자가 서로 다른 염색체에 있고 각각 완전 우성이며 유전자 간 상호작용이 없는 단순화된 모형임을 명시하세요. 여러 감수분열에서 생식세포 RY/Ry/rY/ry의 확률은 각각 1/4입니다. 감수분열 한 번마다 네 종류가 반드시 모두 생기는 것처럼 표현하지 마세요. 이론적 표현형은 9:3:3:1이며 모든 유전 현상에 일반화하지 않습니다.

1/10/100/1000회 실험, 이론적 확률과 관찰 빈도 분리, 부모 변경 시 기존 표본 혼합 방지, 2×2와 4×4 교배표 선택 표시를 구현하세요. 표본을 강제로 비율에 맞추거나 표본 증가 때 오차가 항상 감소한다고 설명하지 마세요.

RR×rr, Rr×Rr, rr×rr, RrYy×RrYy의 정확 확률, 빈도 합계, 초기화, 키보드, 작은 화면, 기존 카드 보존을 검사하세요. 모의 검사는 별도 표시합니다. 출처·모형 가정·미검증 항목·실제 실행 결과를 남기고 수정은 최대 2회입니다. 학생용 API 호출·로그인·개인정보 저장은 넣지 마세요.
