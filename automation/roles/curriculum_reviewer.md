# curriculum_reviewer — 교육과정 검토

이 문서는 [공통 역할 규격](README.md)에 따른 향후 실행 지침이다. 현재 검토를 실행한 결과가 아니다.

- 입력: 실제 수업 학년도·학년, 적용 교육과정 원문/출처 ID, 검토 대상 개념, 원문 이용 범위. 현재 미확정값은 미확인으로 전달한다.
- 지침: 학년별 적용 시기와 성취기준을 실제 원문 쪽/절로 확인한다. 이전 학년·판본의 확인을 다른 범위로 확대하지 않는다. 예시 코드를 지어내거나 날짜로 교육과정을 추론하지 않는다.
- 출력: 학년별 대응 표, 확인한 sourceId/locator/기준 문구의 요약, 검토 범위·보류 사유, 독립의 법칙의 필수/보충/심화 판단 근거. 근거가 없으면 needs_evidence다.
- 권한: 읽기 전용. 콘텐츠·설정·승인·공개 상태를 수정하지 않는다. E01 검사 근거를 제공한다.
